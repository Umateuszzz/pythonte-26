Pythonete — Sistema de Pedidos

# Breve descrição do programa

O Pythonete é um programa desenvolvido em Python para simular o atendimento e o registro de pedidos de uma lanchonete. O sistema permite que o usuário informe seu nome, consulte o cardápio, selecione produtos e quantidades e acompanhe o valor total do pedido.

O projeto utiliza estruturas fundamentais da linguagem Python, como funções, estruturas de repetição, estruturas condicionais, variáveis, entrada e saída de dados e operações matemáticas.

# Principais funcionalidades implementadas

* Solicitação e validação do nome do cliente.
* Exibição do cardápio da lanchonete.
* Seleção dos produtos pelo código correspondente.
* Registro dos itens escolhidos.
* Cálculo do subtotal dos pedidos.
* Cálculo do valor total da compra.
* Possibilidade de adicionar mais de um item ao pedido.
* Opção para finalizar o pedido.
* Validação de entradas para evitar informações inválidas.
* Organização do programa por meio de funções.

# Instruções necessárias para executar o programa

1. Instalar o Python no computador, caso ainda não esteja instalado.

2. Abrir o arquivo do projeto em uma IDE ou editor de código, como o Visual Studio Code.

3. Salvar o código em um arquivo com a extensão `.py`, por exemplo:

   `pythonete.py`

4. Executar o arquivo pelo próprio editor ou pelo terminal utilizando:

```bash
python pythonete.py
```

5. Após iniciar o programa, seguir as instruções apresentadas no terminal, informando o nome e selecionando as opções disponíveis no cardápio.
